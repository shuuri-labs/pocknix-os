# pocknix-os docs

User guides for pocknix-os. New here? Start with the [project README](../README.md).

- [install.md](install.md) - flashing the SD card, installing the ROCKNIX bootloader, first boot,
  and updating
- [known-issues.md](known-issues.md) - what does not work, or not well, yet
- [pocknix-control.md](pocknix-control.md) - the in-game control panel: per-game tweaks, fan/CPU
  modes, adding non-Steam games, file sharing, controller calibration and stick lights, and
  system updates
- [pocknix-tools.md](pocknix-tools.md) - the settings app: updates and rollback, SSH, file
  sharing and VPNs, the ROMs folder, the desktop picker, calibration, internal install
- [pocknix-store.md](pocknix-store.md) - installing and removing emulators, Proton versions,
  VPNs, streaming and Plasma Desktop, and their Steam tiles
- [controller-calibration.md](controller-calibration.md) - checking and calibrating the sticks and
  triggers in Pocknix Tools, and resetting them to the factory settings
- [steam-games.md](steam-games.md) - Steam games: writing your own launch options, and what to try when
  a game won't run
- [emulation-setup.md](emulation-setup.md) - where to put ROMs, BIOS, and firmware, how to launch
  games, and how to tweak emulator settings
- [lepton.md](lepton.md) - running Android apps from your Steam library in Gaming mode
- [waydroid.md](waydroid.md) - running Android apps in the desktop session: setup, installing apps,
  and app shortcuts
- [install-to-internal.md](install-to-internal.md) - moving pocknix from the SD card onto the
  device's internal storage, the bootloader menu that picks what boots, a microSD card for
  games, uninstalling, and restoring the factory bootloader
- [snapshots.md](snapshots.md) - automatic pre-update snapshots, one-button rollback, and
  manual recovery when an update goes wrong
- [licensing.md](licensing.md) - the project license and the third-party components it ships
